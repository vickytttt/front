# Sweet Crumb Bakery

A simple, modern, responsive business website for a fictional bakery, built with HTML, CSS, and JavaScript.

## Business

- **Name:** Sweet Crumb Bakery
- **Type:** Bakery / Cakery
- **Target customers:** Local residents, coffee lovers, and people ordering custom cakes for special occasions
- **Products:** Fresh bread, pastries, cupcakes, cakes and fruit tarts

## Pages / Sections

- **Home** — hero with a call to action
- **About** — the bakery's story
- **Products** — menu with a working category filter
- **Gallery** — featured items
- **FAQ** — collapsible questions
- **Contact** — business info and a validated form

## Files

```
bakery/
├── index.html   # semantic HTML5 structure
├── styles.css   # responsive CSS3 (Flexbox + Grid, media queries)
└── script.js    # mobile nav, product filter, form validation
```

## Run

Open `bakery/index.html` in a browser

## Features

- Fully responsive (desktop, tablet, mobile)
- Slide-in mobile navigation menu
- Product category filter
- Contact form validation
