# Modern CV Web Page

A clean, responsive one-page CV built with **HTML** and **CSS** only, as part of the "Modern CV Web Page" frontend project.

## Features

- Two-column layout: left sidebar with profile, contact, and skills; right column with About Me, Experience, and Education
- Built with **CSS Flexbox** and semantic **HTML5** elements
- Responsive design that adapts to desktop and mobile
- Simple, professional color and typography scheme
- Hover effects on skills and links

## Project Structure

```
cv/
├── index.html
├── style.css
└── assets/
    └── avatar.svg
```

## How to Run

Open `index.html` in any modern web browser.

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, custom properties)
